Usher

Usher files finished video downloads into the folder that the Infuse media player reads.

What it does

Usher is a small personal tool. It watches a downloads folder on a home server.

When a download has stopped changing, usher looks each video up on TMDB, renames it the way Infuse expects, and moves it to the movies, TV shows or anime folder. It then removes what the download left behind, such as sample clips and text notes.

It never overwrites a file already in the library. A video it cannot identify stays where it is.

Examples

  • Pulp.Fiction.1994.1080p.mkv becomes Movies/Pulp Fiction (1994)/Pulp Fiction (1994) {tmdb-680}.mkv
  • Breaking.Bad.S01E02.720p.mkv becomes Shows/Breaking Bad/Season 1/Breaking Bad S01E02 {tmdb-1396}.mkv
  • Sousou no Frieren - 05 (1080p).mkv becomes Anime/Frieren Beyond Journey's End/Season 1/Frieren Beyond Journey's End S01E05 {tmdb-209867}.mkv

How it uses TMDB

Usher searches TMDB for a movie or show by the title and year found in the file name.

For a show it reads the alternative titles and the number of episodes in each season. That is how it recognises a romanised anime title and turns an absolute episode number into a season and episode.

It takes the official title, the year and the TMDB id from the result, and writes them into the file name. Infuse then fetches its own metadata.

Usher only reads from the API. It makes a few requests per download, for personal, non-commercial use, and it does not republish TMDB data.

This product uses the TMDB API but is not endorsed or certified by TMDB.

How it is built

  • Python 3.13, standard library only, no dependencies.
  • It runs as one Docker container.
  • Unit tests cover the name parser, the Infuse paths and the filing logic.
